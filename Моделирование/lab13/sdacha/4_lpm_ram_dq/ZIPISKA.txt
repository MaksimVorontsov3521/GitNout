ФУНКЦИЯ. ОЗУ 1024 слов по 8 бит (8192 бит = 8 Кбит), одиночный порт,
асинхронное чтение. Наружу выведены только WE, ADDRESS[9..0], DATA[7..0] и
Q[7..0], как требует задание; inclock и outclock НЕ подключены намеренно:
lpm_ram_dq.tdf объявляет оба с умолчанием VCC, и при трёх UNREGISTERED в
конструкции не остаётся ни одного регистра, которому нужен такт, так что
четыре
порта - действительно весь интерфейс. Режим, который построил Quartus: Single
Port, глубина 1024, ширина 8, файл инициализации none.

НЕВЕРНА: гость сохранил 0xFF, 0xF0, 0xA5, 0x5A по адресам 0x000, 0x155,

   0x3FF (см. таблицу ниже - это прочитано обратно из lpramax.sim.vwf).
Из кандидатов правил записи только одно объясняет все 28 измеренных фаз
   обеих проб:
хранение происходит по спаду WE, беря адрес и данные в момент ПОСЛЕ
   перехода; при WE = 1 адресованное слово проходит на Q напрямую; адрес, в
   который ни разу не записывали, читается как X.
   Кандидаты отвергнуты числом расхождений (раздел candidates в
   report_data.json; lpramax/lpramwb):
      write=we-fall  sample=post   расхождений lpramax  0, lpramwb  0
      write=we-fall  sample=pre    расхождений lpramax  0, lpramwb  5
      write=we-rise  sample=post   расхождений lpramax  0, lpramwb  3
      write=we-rise  sample=pre    расхождений lpramax  0, lpramwb  2
      write=we-level sample=post   расхождений lpramax  0, lpramwb  5
      write=clk-rise sample=post   расхождений lpramax 12, lpramwb  8
      write=none     sample=post   расхождений lpramax  8, lpramwb  3
Решающий эксперимент - lpramwb. В фазе 3 читается 0x00 по адресу 0x010, а
   не
   0x11 из фазы 1: значит удержание происходит НЕ в момент фронта WE и не всё
   время, пока WE=1, а в момент СПАДА WE, и берётся адрес и данные уже ПОСЛЕ
   перехода (в фазе 3 адрес уже переехал на 0x010, а данные сброшены на 0x00).
   Прозрачный замок удержал бы 0x11; край-управляемый по WE с предпереходными
   операндами записал бы 0x11 в 0x010 и 0x22 в 0x020 - отвергнуто, см. строку
we-fall/pre в таблице выше (5 расхождений). Незаписанное слово 0x020 в фазе
   10 по-прежнему X - модель предсказывает
   это, и волна подтверждает.
   Правило следует и из подлинного источника. Цитаты построчные, сверены с
   ref_altera/mega/altram.tdf (508 строк, 19783 байт):
строки 61–66   RAM_MODES: при USED(clocki) = 0 левая ветвь вырождается в
      0, то есть регистрация отсутствует
строки 83      STRATIX_RAM_POSSIBLE() = USED(clocki) &
      (REGISTERINPUTMODE == "ALL" # "DEFAULT")
строки 86      STRATIX_RAM_NOT_IMPOSSIBLE() = (USED(clocki) #
      USED(clocko)) & (NO_BENCHMARKING() != 1)
строки 236–237 ASSERT, выдающий «Can't convert single-port RAM ...
      supports only synchronous single-port RAM» с SEVERITY ERROR
      строки 427     real_we[0] = we (ветвь без порта byte-enable)
строки 439–441 IF (USED(clocki)) GENERATE segment[bank][bit].clki =

строки 449     segment[bank][bit].we = real_we[bank] — строб записи

   Следствие для отчёта, важное для любого, кто строит диаграмму памяти:
корректная временная диаграмма памяти обязана удерживать адрес и данные ещё
