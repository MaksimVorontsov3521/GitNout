D:\Desktop\NF\lab13\work\<проект> на хосте); C:\altera\quartus50\... -
место установки. Ни тот, ни другой путь читателю не нужен: все файлы, которые

мегафункции установки - в ref_altera/. Журналы НЕ правились: это
доказательства, и

перечисляет c:/altera/quartus50/libraries/megafunctions/... именно так, как
прочитал их гость).

ГДЕ ИСКАТЬ ОТЧЁТЫ. Здесь журналы названы по ПРОГОНУ драйвера, а не по
проекту: один вызов quartus_map/fit/asm/tan обслуживает несколько
проектов, поэтому, например, r202611262105_ram4-mem4x8.log покрывает оба
проекта сразу, а a202611262107_lpramax.log - один запуск по одному
проекту. Отдельного .rpt на каждый вызов здесь НЕТ и быть не должно:
постраничные отчёты по проекту лежат в папках заданий - 1_ram4, 2_ram4beh,
3_mem4x8, 4_lpm_ram_dq, 5_proby_polyarnosti - там .map.rpt/.fit.rpt/
.asm.rpt/.tan.rpt/.sim.rpt/.flow.rpt, .map.eqn, .fit.eqn и .pin. Требование
«каждый снятый запуск документирован» выполняется так: запуск - журналом
здесь, результат проекта - отчётом там; сверка по времени и имени проекта
между двумя этими наборами и есть проверка, что ни один прогон не потерян.

ЦЕПОЧКА ЗАМКНУТА ВНУТРИ СДАЧИ. Отчёты из папок заданий - это тот самый корпус,
против которого трассированы измеренные числа отчёта (6_proverki,
_audit_final.py).
Упаковщик сверяет этот корпус с рабочим каталогом гостя work/ ПОБАЙТОВО по
sha256,
а не по имени и не по размеру. Метод: множество имён .rpt/.eqn/.pin из work
сопоставляется множеству имён тех же расширений в папках
1_ram4..5_proby_polyarnosti,
и каждое доставленное имя обязано найти свой побайтовый аналог в work.
Результат последней сборки: work 73 файлов, 69 имён;
сдача 69 файлов, 69 имён; пар сравнения 69;
расхождений sha256 0; без аналога в сдаче 0 имён;
без аналога в work 0 имён. Дубликаты work (4)
лежат в *_out-подкаталогах и совпадают по имени с доставляемыми, поэтому
сравнивается множество имён, а не число файлов.
То есть: прогон документирован журналом здесь, результат прогона - отчётом
там, а
число отчёта трассировано в этот же доставленный отчёт. Цепочка замыкается
внутри
сдачи и не требует ни work/, ни авторского дерева.
