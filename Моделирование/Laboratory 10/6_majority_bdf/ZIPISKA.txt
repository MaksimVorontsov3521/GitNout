ЗАДАНИЕ 6. Мажоритарный элемент (графическая схема)
=====================================================

ФАЙЛ: majority.bdf - три AND2 -> OR3 дают M; два XOR дают адрес отличившегося
      входа. majority.vwf - перебор 8 комбинаций, шаг 100 нс.

   M  = X1*X2 OR X1*X3 OR X2*X3       (голос большинства)
   a1 = X2 XOR X3
   a0 = X1 XOR X3

АДРЕС a1a0:  01 - отличается X1
             10 - отличается X2
             11 - отличается X3
             00 - все входы равны (обычное состояние)

ЧТО ДЕЛАТЬ: majority.qpf -> Analysis & Synthesis -> Functional Simulation.

ТАБЛИЦА (из majority.sim.vwf):
  X1 X2 X3 | M a1 a0 | смысл
   0  0  0 | 0  0  0 | все равны
   0  0  1 | 0  1  1 | отличается X1
   0  1  0 | 0  1  0 | отличается X2
   0  1  1 | 1  0  1 | большинство 1
   1  0  0 | 0  0  1 | отличается X3  <-- в методичке тут M=1, это ОПЕЧАТКА
   1  0  1 | 1  1  0 | большинство 1
   1  1  0 | 1  1  1 | большинство 1
   1  1  1 | 1  0  0 | все равны

ЗАМЕЧАНИЕ К МЕТОДИЧКЕ: в строке X1=1, X2=0, X3=0 напечатано M = 1, хотя
большинство входов = 0 (одна единица из трёх). Формула даёт M = 0, и Quartus
моделирует 0. Колонки a1 и a0 во всех 8 строках верные - адресация работает.

СМЫСЛ: M повторяет значение большинства - это «голосование» при троировании
(TMR). Одиночная ошибка в одном из трёх каналов исправляется, два других дают
верное большинство.

РЕСУРСЫ: 3 LE, 6 выводов, 0 регистров.
