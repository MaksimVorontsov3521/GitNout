ЗАДАНИЕ 4.2 (вариант на VHDL) = пункт 5 плана: структурная модель канала
==========================================================================

ФАЙЛЫ (три источника ОБЯЗАТЕЛЬНО в одной папке - Quartus ищет .vhd только здесь):
   link_vhd.vhd - верхний уровень: три port map (eo8:tx, dtm:ch, eo8:rx)
   eo8.vhd      - поведенческая модель контроллера (из 3b)
   dtm.vhd      - Y <= W xor ERR (из 4b)
   link_vhd.vwf - те же 10 сценариев, что в 4c
   link_vhd.qsf - VHDL_FILE link_vhd.vhd / eo8.vhd / dtm.vhd (БАЗОВЫЕ имена!),
                  TOP_LEVEL_ENTITY link_vhd

ЧТО ПОКАЗЫВАЕТ ЛИСТ КОДОМ:
   tx: entity work.eo8 port map (X => X, X8 => '0', EVEN => P, ODD => open);
   W <= P & X;                      - 9-битное слово {P, X[7..0]}
   ch: entity work.dtm port map (W => W, ERR => ERR, Y => R);
   rx: entity work.eo8 port map (X => R(7 downto 0), X8 => R(8), ...);
   Outp <= R(7 downto 0);
То есть структура 1-в-1 повторяет link.bdf, включая GND на девятом входе
передатчика (там '0').

ГЛАВНАЯ ПРОВЕРКА ПУНКТА: совпадают ли диаграммы с заданием 4.2?
   Сопоставление поимённо (X{i} <-> X[{i}], ERR{i} <-> ERR[{i}],
   Out{i} <-> Outp[{i}]) дало 27 из 27 каналов с ОДИНАКОВЫМИ временными
   диаграммами. Совпадение полное, потому что моделирование функциональное -
   задержек нет.
   Ресурсы тоже совпали: 11 LE / 27 выводов против 11 LE / 27 выводов в 4c.

../vhdl/eo8.vhd - Quartus резолвит путь относительно папки проекта и выдаёт
   Warning: Can't analyze file ... file C:/dsh/vhdl/eo8.vhd is missing
   Error: VHDL Use Clause error: design library "work" does not contain "eo8"
Только базовое имя файла, и все три .vhd лежат рядом.
