ЗАДАНИЕ 1 (вариант на VHDL). Ячейка чётности, поведенческая модель
==================================================================

СХЕМА:  parity2.vhd   - тот же файл проекта, что и в 1a, но описание текстовое
        Ech <= (x0 xor x1) xor c;   En <= not Ech;
        Промежуточный сигнал t = x0 xor x1 повторяет элемент u1 с листа.

ПОЧЕМУ ДВЕ ПАПКИ: задание 1 можно сдать и схемой, и кодом. Порт-имена
(x0, x1, c, Ech, En) в обоих вариантах ОДИНАКОВЫЕ, поэтому таблицы истинности
сравниваются построчно, а не «на глаз».

ЧТО ДЕЛАТЬ В QUARTUS:
  1. File -> Open Project -> parity2.qpf
  2. Processing -> Start Analysis & Synthesis  (в логе: Elaborating entity "parity2")
  3. Generate Functional Simulation Netlist -> Run Simulation Tool -> Functional

ПРОВЕРКА: parity2.sim.vwf даёт те же 8 строк, что и 1a (таблица в ZIPISKA.txt
папки 1a). Совпадение полное - значит графическая и текстовая записи
эквивалентны.

СИНТЕЗИРУЕМОСТЬ: только ieee.std_logic_1164, статические конкурентные
присваивания, без wait/after. Ресурсы такие же: 1 LE, 5 выводов, 0 регистров.

СТАТУС ДОКАЗАТЕЛЬСТВА: получено из Quartus II 5.0 (гостевая Windows XP).
   parity2.sim.vwf - перебор 8 комбинаций, PASS 8/8, расхождений нет.
   Сравнение с 1a (графикой): Ech и En совпали ПОСТРОЧНО во всех 8 строках.
   Ресурсы: 1 логический элемент (комбинационный), 5 выводов, 0 регистров -
   ровно как у схемы в 1a. Все этапы: MAP/FNET/SIM/FIT/ASM/TAN = 0 ошибок.

ПЕРЕД ЭТИМ БЫЛА НАСТОЯЩАЯ ОШИБКА, которую поймал Quartus:
   Error: VHDL Interface Declaration error in parity2.vhd(30):
          interface object "Ech" of mode out cannot be read.
          Change object mode to buffer or inout.
Причина: первая редакция писала  En <= not Ech;  то есть ЧИТАЛА выход.
VHDL-93 читать OUT запрещает. Исправлено переносом значения на внутренний
сигнал:  ech_sig <= t xor c;  Ech <= ech_sig;  En <= not ech_sig;
Порты остались чистыми OUT (буферы/inout не понадобились, синтез чище).
Это типичная ошибка VHDL, которой в графической версии нет: в .bdf провод
можно ветвить сколько угодно, а в тексте выход - только источник.
