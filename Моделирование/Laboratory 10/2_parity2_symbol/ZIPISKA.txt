ЗАДАНИЕ 2. Символ ячейки в библиотеке проекта
================================================

ФАЙЛ:   parity2.bsf  - это и есть символ. Рядом лежит parity2.bdf (та же схема),
        qpf/qsf/vwf - чтобы папка открывалась в Quartus как самостоятельный проект.

КАК КВАРТУС ПОЛУЧАЕТ СИМВОЛ:
  В GUI: File -> Create/Update -> Create Symbol Files for Current File.
  В командной строке такой операции НЕТ (проверено: quartus_map не порождает
  .bsf, а ключи --convert_bdf_to_verilog / --convert_bdf_to_vhdl требуют имени
  проекта и дают ошибку). Поэтому .bsf формируется на хосте по формату,
  обратному к аутентичным файлам лабораторий (CMP_2bit.bsf, encoder_8-3.bsf):
  заголовок (header "symbol" (version "1.1")), рамка (16,16)-(112,112),
  выводы с шагом 16 px начиная с y = 32.

ВИД СИМВОЛА: входы x0, x1, c слева; выходы Ech, En справа (см. sym_parity2.png).

ОБЯЗАТЕЛЬНОЕ ОБЪЕДИНЕНИЕ: копию parity2.bsf ВМЕСТЕ с parity2.bdf кладут в папку
каждого проекта, который ячейку использует, то есть в 3a_eo8_bdf и 4c_link_bdf.
Кварус ищет символ только в папке проекта - относительные пути не работают.

КАК ПРОВЕРИТЬ, ЧТО СИМВОЛ ПРИНЯТ: в 3a и 4c блок «parity2» стоит на листе,
проект компилируется (0 ошибок, 0 предупреждений) - значит .bsf распознан.
В Symbol Tool: View -> Symbol Files (Library = Project).
