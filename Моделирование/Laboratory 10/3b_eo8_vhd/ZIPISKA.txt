ЗАДАНИЕ 3 (вариант на VHDL) = пункт 5 плана: поведенческая модель eo8
======================================================================

ФАЙЛ: eo8.vhd - свёртка девяти входов циклом for ... loop по std_logic_vector,
      без элементов и экземпляров: чистое описание поведения.
      EVEN <= not ODD; ODD = XOR всех битов X.

ЧТО ДЕЛАТЬ: открыть eo8.qpf -> Start Analysis & Synthesis ->
Generate Functional Simulation Netlist -> Functional Simulation.

ПРОВЕРКА НА СИНТЕЗИРУЕМОСТЬ (это же заготовка для задания 8):
  - библиотека только ieee + std_logic_1164;
  - цикл статический, граница (0 to 8) известна синтезатору;
  - нет wait, after, временных диаграмм внутри процесса;
  - одна присваиваемая переменная на выход => защёлок нет.
Результат: 3 LE, 11 выводов, 0 регистров, 0 бит памяти - идентично схеме 3a.
Значения 512 строк совпали со схемой: см. eo8.sim.vwf.

здесь ответ: ресурсы и таблица совпали построчно.
