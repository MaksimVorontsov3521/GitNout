ЗАДАНИЕ 3. Пирамида eo8 - аналог КР1533ИП5 (графическая схема)
=================================================================

ФАЙЛЫ В ПАПКЕ (три уровня иерархии - всё вместе, порознь не работает):
   eo8.bdf         - верхний лист: 4 экземпляра ячейки + 9 выходов X0..X8
   eo8.bsf         - символ этого контроллера (пригодится в задании 4)
   parity2.bdf     - дочерняя схема из задания 1
   parity2.bsf     - её символ из задания 2  <-- без него лист не соберётся
   eo8.vwf         - перебор всех 512 комбинаций
   eo8.qsf/.qpf    - BDF_FILE eo8.bdf + BDF_FILE parity2.bdf (.bsf не перечисляется)

СХЕМА:   U1 = (X0,X1,X2) -> s0
          U2 = (X3,X4,X5) -> s1
          U3 = (X6,X7,X8) -> s2
          U4 = (s0,s1,s2) -> Ech = ODD,  Eн = EVEN
   Выходы En у U1..U3 оставлены НЕподключёнными - для выходов это допустимо,
   а вот висящие ВХОДЫ Quartus не принимает.

ЛОГИКА: ODD = X0^X1^...^X8 (XOR всех девяти входов), EVEN = НЕ ODD.
   E = 1 при чЁТНОМ весе слова, O = 1 при нечётном - ровно поведение ИП5.

ЧТО ДЕЛАТЬ: открыть eo8.qpf -> Start Analysis & Synthesis ->
Generate Functional Simulation Netlist -> Run Simulation Tool -> Functional.
В волнах группа X, Count Value 0..511, шаг 10 нс.

КОНТРОЛЬНЫЕ ТОЧКИ (из eo8.sim.vwf):
   X, hex | вес | EVEN ODD
   000    |  0  |  1    0
   001    |  1  |  0    1
   003    |  2  |  1    0
   0A5    |  4  |  1    0
   0FF    |  8  |  1    0
   155    |  5  |  0    1
   1FF    |  9  |  0    1
Все 512 строк совпали с ожидаемой таблицей, расхождений нет.

РЕСУРСЫ: 3 логических элемента (все комбинационные), 11 выводов, 0 регистров.
