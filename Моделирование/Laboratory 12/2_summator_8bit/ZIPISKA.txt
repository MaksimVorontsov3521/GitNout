ФУНКЦИЯ: S[7..0] = A[7..0] + B[7..0] + CI; CO - переполнение старшей ИС

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Две ИС 7483. Младшая складывает A[3..0], B[3..0] с CI; её C4 подключён
   к C0 старшей, которая складывает A[7..4], B[7..4]. Внутри каждой ИС
   перенос опережающий, между ИС - последовательный: старшая ждёт C4 от
   младшей. Задержка = проход младшей (формирование переноса) + проход
   старшей (проведение переноса до суммы).

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   Сквозной перенос через все 8 разрядов: FF+01 (CI=0)=00 CO=1; 80+80=00
   CO=1; FF+FF+1=FF CO=1. Точность 8-битного каскада подтверждена на 131
   072 состояниях.

   СИМУЛЯЦИЯ: 8 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в add8.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (add8, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 20
      выводов (pins)         : 26
      худшая задержка tpd    : 11.920 нс  (CI -> S[7])
      доля логики/межсоедин. : 37.13 % / 62.87 %
      критический путь : CI -> 7483:U1|51~214 -> 7483:U1|1~212 ->
      7483:U1|1~213 -> 7483:U2|1~106 -> 7483:U2|1~107 -> 7483:U2|1~108 ->
      7483:U2|45 -> S[7]
