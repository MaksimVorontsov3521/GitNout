ФУНКЦИЯ: F[7..0] = A[7..0] op B[7..0] + Cin; общий код S[3..0], общий CN

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Две 74181 по варианту 1 главы. CN младшей U1 получает общий входной
   перенос; её CN4 -> CN старшей U2; итоговый перенос - CN4 U2. Коды S
   объединены в шину S[3..0], операнды в A[7..0]/B[7..0], результат
   F[7..0]. Провод CN4(U1)->CN(U2) даёт точный 8-битный результат во всех
   131 072 состояниях - это требование рисунка 17.7, подтверждённое
   измерением.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   96 наборов (6 кодов x 8 пар x 2 CN), 0 расхождений с расчётом.

   СИМУЛЯЦИЯ: 96 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в alu8.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (alu8, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 39
      выводов (pins)         : 31
      худшая задержка tpd    : 13.134 нс  (S[2] -> F[5])
      доля логики/межсоедин. : 37.73 % / 62.27 %
      критический путь : S[2] -> 74181:U1|46~51 -> 74181:U1|66~19 ->
      74181:U1|78~134 -> 74181:U1|78~135 -> 74181:U2|79 -> 74181:U2|81 ->
      F[5]
