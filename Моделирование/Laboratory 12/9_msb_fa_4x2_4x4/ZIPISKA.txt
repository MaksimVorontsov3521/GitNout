ПРОЕКТ fa1: Собственный одноразрядный полный сумматор X, Y, Cin -> S, Cout
--------------------------------------------------------------------------
ФУНКЦИЯ: S = X ⊕ Y ⊕ Cin; Cout = X·Y + Cin·(X ⊕ Y)

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Строительный кирпич для МСБ. Собран из базовых вентилей (не из 7483),
   чтобы выполнить требование задания строить МСБ именно на собственном
   элементе. Для него создан символ (.bsf), чтобы использовать его как
   библиотечный элемент на следующих листах.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   8 наборов, 0 расхождений (полная таблица 3 входов).

   СИМУЛЯЦИЯ: 8 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в fa1.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (fa1, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 2
      выводов (pins)         : 5
      худшая задержка tpd    : 8.694 нс  (Y -> Cout)
      доля логики/межсоедин. : 44.36 % / 55.64 %
      критический путь : Y -> O1~66 -> Cout

ПРОЕКТ mac42: МСБ 4x2 на собственных одноразрядных сумматорах
--------------------------------------------------------------------------
ФУНКЦИЯ: P[5..0] = A[3..0]*B[1..0] + C[3..0] + D[1..0]

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Множительно-суммирующий блок: умножение 4-разрядного числа на
   2-разрядное с одновременным приложением C и D. Частные произведения и
   цепочка собственных fa1-сумматоров складывают столбцы матрицы вместе с
   входами C, D. Использует символ fa1 из предыдущей папки.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   Исчерпывающе на всех 4096 комбинациях. Контроль: 15*3+15+3=63 (111111),
   5*2+1+1=12 (001100), 15*3=45 (101101).

   СИМУЛЯЦИЯ: 50 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в mac42.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (mac42, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 24
      выводов (pins)         : 18
      худшая задержка tpd    : 11.491 нс  (D1 -> P4)
      доля логики/межсоедин. : 42.37 % / 57.63 %
      критический путь : D1 -> fa1:G2|X2~12 -> fa1:H2|O1~1 -> fa1:H3|O1~1
      -> fa1:H4|O1~1 -> fa1:H5|X2 -> P4

ПРОЕКТ mac44: МСБ 4x4 на собственных одноразрядных сумматорах
--------------------------------------------------------------------------
ФУНКЦИЯ: P[7..0] = A[3..0]*B[3..0] + C[3..0] + D[3..0]

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Расширение МСБ4x2 до четырёх разрядов множителя: матрица частных
   произведений 4x4, столбцов больше, цепочка fa1-сумматоров длиннее. Для
   МСБ4x4 создан символ (.bsf) - он требуется заданием для сборки в
   задании 10.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   Исчерпывающе на всех 65 536 комбинациях. Контроль: 15*15+15+15=255
   (11111111), 9*6+3+2=59 (00111011).

   СИМУЛЯЦИЯ: 53 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в mac44.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (mac44, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 47
      выводов (pins)         : 24
      худшая задержка tpd    : 14.724 нс  (A0 -> P7)
      доля логики/межсоедин. : 37.08 % / 62.92 %
      критический путь : A0 -> mac42:U|fa1:F2|X2~41 ->
      mac42:U|fa1:F2|X2~42 -> mac42:U|fa1:H3|O1~1 -> mac42:U|fa1:H4|O1~1

      -> mac42:L|fa1:H5|O1~1 -> mac42:L|fa1:H6|X2 -> P7

ЧТО ДЕЛАТЬ В QUARTUS II 5.0: 1. File -> Open Project -> <имя>.qpf (НЕ .bdf
открывать!) 2. Processing -> Start Analysis & Synthesis - проверить, что схема
читается 3. Processing -> Generate Functional Simulation Netlist 4. Tools ->
Run Simulation Tool -> Functional Simulation - получить волны (*.sim.vwf) 5.
Processing -> Start Timing Analysis - получить задержку (*.tan.rpt) Все файлы
уже на месте; папку нельзя расформировывать: Quartus ищет детские .bdf,
символы .bsf и источники VHDL только в каталоге проекта.
