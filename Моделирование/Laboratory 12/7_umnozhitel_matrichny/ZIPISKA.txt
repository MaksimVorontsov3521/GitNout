ФУНКЦИЯ: P[7..0] = A[3..0] * B[3..0]

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Матрица частных произведений A[i]·B[j], сдвинутых на j. 16 элементов И
   (по клетке матрицы) и три 7483, суммирующих строки по столбцам с
   переносами. Переносы между сумматорами идут по сдвинутой схеме (выход
   суммы среднего разряда -> соответствующий вход следующего), что
   обеспечивает правильное взвешивание столбцов.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   Исчерпывающе на всех 256 парах: P=A*B. Контроль: 15*15=225 (11100001),
   12*13=156 (10011100).

   СИМУЛЯЦИЯ: 12 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в mult4.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (mult4, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 35
      выводов (pins)         : 16
      худшая задержка tpd    : 13.839 нс  (A[0] -> P[6])
      доля логики/межсоедин. : 36.89 % / 63.11 %
      критический путь : A[0] -> 7483:AD1|51~45 -> 7483:AD1|44 ->
      7483:AD2|51~227 -> 7483:AD2|44 -> 7483:AD3|1~602 -> 7483:AD3|1~603
      -> 7483:AD3|45 -> P[6]

читается 3. Processing -> Generate Functional Simulation Netlist 4. Tools ->

Processing -> Start Timing Analysis - получить задержку (*.tan.rpt) Все файлы
