ПРОЕКТ alu8la: 8-разрядное АЛУ из двух 74181 и одной 74182 (рис. 17.8)
--------------------------------------------------------------------------
ФУНКЦИЯ: то же, что alu8, но перенос между группами формирует 74182

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Младшая U1 получает CN напрямую. GN и PN обеих ИС -> на 74182;
   неиспользуемые группы 2,3 заземлены (PN2=PN3=GN2=GN3=0). Выход CX
   старшей группы -> CN U2. Итоговый CN4 - со старшей ИС. ВАЖНО: на 8
   битах 74182 МЕДЛЕННЕЕ каскада (alu8), потому что она подменяет
   единственный переход CN4->CN, добавляя свою логику. Выигрыш появляется
   только при 4 группах (см. alu16la).

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   96 наборов, 0 расхождений. Точные функции 74182 проверены на 512/512
   состояниях; CN4=!GN+CN·!PN на 16384/16384.

   СИМУЛЯЦИЯ: 96 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в alu8la.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (alu8la, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 39
      выводов (pins)         : 31
      худшая задержка tpd    : 14.822 нс  (S[3] -> CN4)
      доля логики/межсоедин. : 37.94 % / 62.06 %
      критический путь : S[3] -> 74181:U1|47~56 -> 74181:U1|74~107 ->
      74182:C1|31~285 -> 74182:C1|31~286 -> 74181:U2|73~15 ->
      74181:U2|78~29 -> 74181:U2|78~30 -> CN4

ПРОЕКТ alu16r: 16-разрядное АЛУ из четырёх 74181, последовательный перенос
(сравнительный опыт)
--------------------------------------------------------------------------
ФУНКЦИЯ: F[15..0] = A[15..0] op B[15..0] + Cin; каскад CN4->CN

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Четыре 74181 цепочкой: CN4 каждой -> CN следующей. Собран, чтобы
   измерить закон масштабирования каскада и честно показать, где 74182
   выигрывает, а где нет.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   512 наборов, 0 расхождений.

   СИМУЛЯЦИЯ: 512 наборов входов, 0 расхождений с расчётом (ответ записал

ПРОЕКТ alu16la: 16-разрядное АЛУ из четырёх 74181 и одной 74182 (полное
использование CRU)
--------------------------------------------------------------------------
ФУНКЦИЯ: F[15..0] = A[15..0] op B[15..0] + Cin; параллельный перенос через
74182

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Четыре 74181 (группы 0..3) и одна 74182, использующая все свои четыре
   группы. GN/PN всех четырёх -> 74182; CI = CN; CX/CY/CZ -> CN блоков
   1/2/3. Здесь 74182 подменяет ТРИ перехода каскада одним уровнем
   опережающей логики и ВЫИГРЫВАЕТ у alu16r по задержке, занимая при этом
   меньше LE. Это и есть объяснение выигрыша из задания 5.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   512 наборов, 0 расхождений. Сравнение с alu16r на одинаковых парах - в
   отчёте, раздел 9.3.

   СИМУЛЯЦИЯ: 512 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в alu16la.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (alu16la, из отчётов quartus_fit / quartus_tan,
