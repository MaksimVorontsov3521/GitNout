ФУНКЦИЯ: FA=B, FA<B, FA>B для беззнаковых A[3..0], B[3..0]

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   74181 в режиме вычитания: код S=0110, M=L, CN=L, даёт F=A-B. Сигналы:
   FA=B = NOR всех разрядов F; FA<B = CN4; FA>B = !CN4 · (F<>0).
   Полярность выведена измерением, как требует задание (строки 230-234,
   290), а не принята из текста.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   Исчерпывающе на всех 256 парах слов. Случаи 0 и максимальных слов:
   1111=1111 -> FA=B; 0000<1111 -> FA<B; 1111>0000 -> FA>B.

   СИМУЛЯЦИЯ: 14 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в cmp4.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (cmp4, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 11
      выводов (pins)         : 15
      худшая задержка tpd    : 10.615 нс  (B[0] -> GT)
      доля логики/межсоедин. : 41.90 % / 58.10 %
      критический путь : B[0] -> 74181:U1|72~27 -> 74181:U1|74 ->
      74181:U1|77 -> G1 -> G4 -> GT

открывать!) 2. Processing -> Start Analysis & Synthesis - проверить, что схема
читается 3. Processing -> Generate Functional Simulation Netlist 4. Tools ->
Run Simulation Tool -> Functional Simulation - получить волны (*.sim.vwf) 5.
Processing -> Start Timing Analysis - получить задержку (*.tan.rpt) Все файлы
