ПРОЕКТ mac48a: МСБ 4x8, вариант A: из двух МСБ 4x4
--------------------------------------------------------------------------
ФУНКЦИЯ: P[11..0] = A[3..0] * B[7..0]

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   B[7..0] разбит на две четверки. Младший блок U: U=A*B[3..0] (C=D=0).
   Старший L: L=A*B[7..4]+C, где C=U[7..4], D=0. Итог P[3..0]=U[3..0],
   P[11..4]=L[7..0]. Контроль ступени: max L = 225+15 = 240 <= 255.
   Использует символ mac44.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   Исчерпывающе на всех 4096 комбинациях. Главная точка
   15*255=3825=111011110001; также 15*15=225=000011100001,
   1*255=255=000011111111.

   СИМУЛЯЦИЯ: 44 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в mac48a.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (mac48a, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 63
      выводов (pins)         : 24
      худшая задержка tpd    : 17.752 нс  (A2 -> P10)
      доля логики/межсоедин. : 36.46 % / 63.54 %
      критический путь : A2 -> mac44:U|mac42:U|fa1:F2|O1~4 ->
      mac44:U|mac42:U|fa1:F2|O1~10 -> mac44:U|mac42:U|fa1:F3|X2 ->
      mac44:U|mac42:L|fa1:H2|O1~1 -> mac44:U|mac42:L|fa1:H3|O1~1 ->
      mac44:U|mac42:L|fa1:H4|X2 -> mac44:L|mac42:U|fa1:H2|O1~1 ->
      mac44:L|mac42:U|fa1:H3|O1~1 -> mac44:L|mac42:U|fa1:H4|X2~17 ->
      mac44:L|mac42:L|fa1:H2|O1~1 -> mac44:L|mac42:L|fa1:H3|O1~1 ->
      mac44:L|mac42:L|fa1:H4|O1~1 -> mac44:L|mac42:L|fa1:H5|X2 -> P10

ПРОЕКТ mac48b: МСБ 4x8, вариант B: из четырёх МСБ 4x2 (цепочка со сдвигом на
2)
--------------------------------------------------------------------------
ФУНКЦИЯ: P[11..0] = A[3..0] * B[7..0]

ЛОГИКА И ПРИНЦИП РАБОТЫ:
   Четыре МСБ4x2 цепочкой со сдвигом на 2 разряда: ступени U0..U3
   обрабатывают по две разряда B; на каждой C=U(i-1)[5..2], D=0. Итог
   P[1..0]=U0[1..0], P[3..2]=U1[1..0], P[5..4]=U2[1..0],
   P[11..6]=U3[5..0]. Контроль ступени: max 45+15=60<=63. Использует
   символ mac42.

ПРОВЕРКА ПРАВИЛЬНОСТИ:
   Исчерпывающе на всех 4096 комбинациях. Задержка и ресурсы СОВПАЛИ с
   вариантом A (синтез уплощает иерархию) - см. отчёт раздел 14.3.

   СИМУЛЯЦИЯ: 44 наборов входов, 0 расхождений с расчётом (ответ записал
   Quartus II в mac48b.sim.vwf).
   РЕСУРСЫ И ЗАДЕРЖКА (mac48b, из отчётов quartus_fit / quartus_tan,
   EP1S10F484C5):
      элементов логики (LE)  : 63
      выводов (pins)         : 24
      худшая задержка tpd    : 17.752 нс  (A2 -> P10)
      доля логики/межсоедин. : 36.46 % / 63.54 %
      критический путь : A2 -> mac42:S0|fa1:F2|O1~4 ->
      mac42:S0|fa1:F2|O1~10 -> mac42:S0|fa1:F3|X2 -> mac42:S1|fa1:H2|O1~1
      -> mac42:S1|fa1:H3|O1~1 -> mac42:S1|fa1:H4|X2 ->
      mac42:S2|fa1:H2|O1~1 -> mac42:S2|fa1:H3|O1~1 ->
      mac42:S2|fa1:H4|X2~17 -> mac42:S3|fa1:H2|O1~1 ->
      mac42:S3|fa1:H3|O1~1 -> mac42:S3|fa1:H4|O1~1 -> mac42:S3|fa1:H5|X2
      -> P10

ЧТО ДЕЛАТЬ В QUARTUS II 5.0: 1. File -> Open Project -> <имя>.qpf (НЕ .bdf
открывать!) 2. Processing -> Start Analysis & Synthesis - проверить, что схема
читается 3. Processing -> Generate Functional Simulation Netlist 4. Tools ->
Run Simulation Tool -> Functional Simulation - получить волны (*.sim.vwf) 5.
Processing -> Start Timing Analysis - получить задержку (*.tan.rpt) Все файлы
уже на месте; папку нельзя расформировывать: Quartus ищет детские .bdf,
символы .bsf и источники VHDL только в каталоге проекта.
