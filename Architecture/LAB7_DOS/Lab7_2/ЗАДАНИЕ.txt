Задание — Lab7_2 (шаг 2 из A7.txt, строки 30)

ФОРМУЛИРОВКА:
  "2. Получите в FPU нечисло (NaN), покажите его в TD."

ЯЗЫК / СРЕДСТВО: C + встроенный ассемблер, компилятор TCC (Turbo C 2.01), модель small (-ms), формат EXE
ИСХОДНИК:  lab7_2.c

ЧТО ДЕЛАЕТ ПРОГРАММА (по пунктам задания):
  1) finit, затем получение NaN НЕСКОЛЬКИМИ способами (A7.txt, строки 67-72, 84-99):
     a) 0.0 / 0.0       -> недействительная операция (I), результат QNaN;
     b) sqrt(-1.0)      -> FSQRT от отрицательного -> I, результат QNaN;
     c) Inf - Inf       -> I, результат QNaN;
     d) 0.0 * Inf       -> I, результат QNaN;
     e) FADD над SNaN   -> I, результат QNaN (SNaN - сигнальное нечисло);
  2) для каждого случая: слово состояния (FSTSW) с разбором бит 0..5, ES, SF,
     TOP, и 80-битный образец результата (FSAVE -> 5 слов) - видно, что мантисса
     у QNaN начинается с 1, у SNaN - с 0 (A7.txt, строки 226-258);
  3) SNaN получается ЗАПИСЬЮ битового шаблона прямо в память float
     (знак 0, порядок 11..11, мантисса 01..1) и загрузкой FLD - так
     демонстрируется таблица специальных значений из задания;
  4) побайтно: NaN в одинарной (КВ) и двойной (ДВ) точности - 4 и 8 байтов;
  5) проверка арифметики с NaN: NaN + 1.0 -> снова NaN, и сравнение FCOM с NaN
     -> взводится C3 (unordered), что и отличает нечисло от бесконечности.

ОСОБЕННОСТИ:
  CR0 из C не читается: TCC порождает ASM без .386 (Undefined symbol: eax),
  поэтому NE не анализируется - см. Plan_Lab7.md п.4a и Lab7_4.
  Все литералы вывода - ASCII. Ожидание клавиши под #ifndef NOWAIT.

КАК ПРОСЛЕДИТЬ В TD (интерактивно, автоматического съёма экрана отладчика нет):
  1) Сборка и запуск через TD (задача "Compile and Debug in TD (DOSBox)").
  2) Точка останова (F2) на строке после fdiv / fsqrt, затем View -> Floating Point.
  3) В окне видны ST(0)..ST(7): у NaN порядок = 7FFFh и старший бит мантиссы = 1
     (QNaN). Слово состояния: бит IE (0) = 1.
  4) Для SNaN: старший бит мантиссы = 0 при ненулевом хвосте - в TD это видно
     как 4000h.. vs 8000h.. в старшем слове мантиссы.
  5) Options -> Debug -> Floating point exceptions (если доступно в этой версии TD):
     там же можно снять маску и наблюдать поведение; в DOSBox исключение не
     доставляется (Plan_Lab7.md п.4c), поэтому ориентироваться на окна регистров.
