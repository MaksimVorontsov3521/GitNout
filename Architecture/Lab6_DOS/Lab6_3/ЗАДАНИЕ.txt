Задание — Lab6_3 (шаг 3 из A6.txt, строки 48–50)

ФОРМУЛИРОВКА:
  "3. Реализуйте выполнение вашей ПП путем создания особого случая
   (деление на нуль), соответствующему одному из первых десяти векторов."

ЯЗЫК / СРЕДСТВО: C + встроенный ассемблер, TCC, модель small (-ms), EXE.

ИСХОДНИК:  Lab6.c

ВЫБРАННЫЙ ВЕКТОР: 00h — Divide Error. Он входит в первые десять:
  00h DIVIDE ERROR, 01h TRAP, 02h NMI, 03h BREAKPOINT, 04h INTO,
  05h BOUND, 06h INVALID OPCODE, 07h DEVICE NOT AVAILABLE,
  08h DOUBLE FAULT, 09h COPROCESSOR SEGMENT OVERRUN.

ЧТО ДЕЛАЕТ ПРОГРАММА:
  1) old_div0 = getvect(0x00)                 — запомнить старый вектор
  2) disable(); setvect(0x00, isr_div0); enable()
  3) параметры ПП: в памяти (Dividend=24680, Divisor=0) и в регистрах
     (asm: mov ax,Dividend / xor dx,dx / mov bx,Divisor / div bx)
  4) DIV с нулевым делителем -> процессор ВОЗБУЖДАЕТ особый случай int 00h
     (источник — внутренняя ошибка ЦП, а НЕ команда INT; при этом
      заполнение стека одинаковое: FLAGS, CS, IP)
  5) ПП обрабатывает данные: видит BX=0 и ЗАМЕНЯЕТ делитель в своём
     стековом кадре ([bp+14] = 1), результат = 24680 / 1
  6) IP ([bp+18]) НЕ трогается -> после IRET процессор ПОВТОРНО исполняет
     DIV, уже с BX=1, и деление завершается успешно
  7) main печатает: 24680 / 1 = 24680, остаток 0 (делитель исправлен на 1)
  8) setvect(0x00, old_div0)                  — восстановить старый вектор

Важно: запись в параметр обработчика (wBX = 1) — это запись прямо в кадр,
поэтому значение реально восстановится при IRET (pop bx).

ЗАПУСК:
  Открыть в VS Code папку Lab6_3  ->  Ctrl+Shift+B
  (задача "Compile and Run (TCC -> DOSBox)")
  Альтернативы: "Compile and Debug in TD (DOSBox)" - отладчик;
              "Selftest: capture output" - сборка+запуск с перехватом
              вывода в build\run.txt (без ожидания клавиши, /dNOWAIT)

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
  IVT[00h] до / после / восстановлен;
  обработчик прочитал AX=6068h DX=0000h BX=0000h, исправил BX := 0001h;
  команда DIV исполнилась ДВАЖДЫ; итог 24680 / 1 = 24680, остаток 0;
  число входов в ПП = 1 (повторный DIV успешен, нового особого случая нет).

ПРОВЕРЕНО АВТОНОМНО (autotest.ps1, вывод в build\run.txt):
  IVT[00h] до 01A3:01A0 -> после установки 01A3:02C3 -> восстановлен 01A3:01A0
  обработчик прочитал AX=6068 DX=0000 BX=0000, исправил BX := 0001 (запись в [bp+14])
  RESULT 24680 / 0 (fixed to 1) = 24680, остаток 0; входов в ПП = 1
