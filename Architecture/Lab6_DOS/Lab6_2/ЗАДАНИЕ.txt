Задание — Lab6_2 (шаг 2 из A6.txt, строка 47)

ФОРМУЛИРОВКА:
  "2. Проанализируйте заполнение стека."

ЯЗЫК / СРЕДСТВО: чистый ассемблер TASM 5.0, модель TINY -> .COM,
сборка tasm /zi + tlink /v /t (на выходе .COM).

ИСХОДНИК:  lab6_2.asm

ЧТО АНАЛИЗИРУЕТСЯ:
  a) программное прерывание INT 0F0h — процессор кладёт 3 слова:
        [SP]=IP, [SP+2]=CS, [SP+4]=FLAGS  (вершина стека — IP)
     и обнуляет TF и IF;
  b) вызов CALL NEAR — 1 слово (только IP);
  c) вызов CALL FAR  — 2 слова (CS:IP), FLAGS НЕ сохраняются;
  d) баланс стека: SP после IRET должен равняться SP до INT;
  e) вектор прерывания = 32-битная ячейка IVT (0000:0000..0000:03FF,
     256 векторов по 4 байта = первые 1 КБ);
  f) установка/восстановление вектора прямой записью в IVT под CLI/STI
     (аналог setvect/getvect + disable/enable);
  g) возврат из ПП — IRET (3 слова), из процедуры — RET (1..2 слова).

КАК СНIMAЕТСЯ ДАННЫЕ:
  Обработчик ISR_F0 на входе сохраняет SpIsr (=SP), снимает 3 слова кадра
  в StkIP/StkCS/StkFL, фиксирует FLAGS внутри ПП (pushf/pop), затем
  делает пролог (push ax..bp), обрабатывает данные (сумма массива + AX + BX),
  восстанавливает регистры и выходит через IRET. Печать — только в main.

ЗАПУСК:
  Открыть в VS Code папку Lab6_2  ->  Ctrl+Shift+B
  (задача "Compile and Run (TASM -> DOSBox)")
  Альтернативы: "Compile and Debug in TD (DOSBox)" - отладчик;
              "Selftest: capture output" - сборка+запуск с перехватом
              вывода в build\run.txt (без ожидания клавиши, /dNOWAIT)

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
  стек вырос на 6 байт = 3 слова;
  StkIP = адрес метки AfterInt, StkCS = CS программы;
  SP после IRET = SP до INT (стек сбалансирован);
  внутри ПП TF=0, IF=0; после IRET — восстановлены;
  CALL NEAR -> 1 слово, CALL FAR -> 2 слова, INT -> 3 слова;
  список разрешённых/запрещённых векторов.

ПРОВЕРЕНО АВТОНОМНО (autotest.ps1, вывод в build\run.txt):
  SP before INT = FFFE -> FFF8 = 6 байт = 3 слова
  [SP+0] IP = 01AA (= адрес метки AfterInt), [SP+2] CS = 0193, [SP+4] FLAGS = 7293
  SP после IRET = FFFE = SP до INT (стек сбалансирован)
  FLAGS: до 7293 (IF=1) -> внутри ПП 7093 (IF=0) -> после IRET 7293 (IF=1)
  CALL NEAR -> 1 слово; INT 0F0h -> 3 слова; CALL FAR -> 2 слова
  SUM(array + AX + BX) = 42B3 (1234h + 0078h + 1000h+2000h+0003h+0004h)
