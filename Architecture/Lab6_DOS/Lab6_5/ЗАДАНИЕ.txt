Задание — Lab6_5 (шаги 3 и 4 на чистом ассемблере)

Это ASM-дубль шагов 3–4: показывает, ЧТО [bp+18] — не магия компилятора,
а следствие пролога. Кадр собирается ВРУЧНУЮ.

ФОРМУЛИРОВКА (A6.txt, строки 48–53):
  "3. Реализуйте выполнение вашей ПП путем создания особого случая
   (деление на нуль)...  4. Проанализируйте заполнение стека. При выходе
   из обработчика прерываний пропустите команду, вызывающую особый случай
   (add [bp+18], 2)."

ЯЗЫК / СРЕДСТВО: чистый ассемблер TASM 5.0, модель TINY -> .COM.

ИСХОДНИК:  lab6_5.asm

РУЧНОЙ ПРОЛОГ В СТИЛЕ BORLAND:
  push ax,bx,cx,dx,es,ds,si,di,bp  +  mov bp,sp
  даёт ровно тот же кадр, что и компилятор:
     [bp+0]=BP ... [bp+16]=AX (9 слов пролога = 18 байт)
     [bp+18]=IP  [bp+20]=CS  [bp+22]=FLAGS  (кладёт процессор)
  Поэтому add word ptr ss:[bp+18], 2 в чистом ASM работает так же,
  как в шаге 4 на Си.

ЧТО ДЕЛАЕТ ПРОГРАММА:
  1) сохранить старый вектор 00h из IVT (прямое чтение 0000:0000)
  2) установить новый (прямая запись в IVT под CLI/STI)
  3) возбудить особый случай: div bx при bx = 0 (Dividend = 24680)
  4) ПП: снять SpIsr, сделать пролог, скопировать 12 слов кадра в Frame,
     зафиксировать IP/CS/FLAGS из кадра ДО изменений
  5) ПП считает 24680 / 7 = 3525 ост. 5 и кладёт результат в слоты
     кадра: [bp+16] = AX, [bp+10] = DX
  6) add word ptr ss:[bp+18], 2  — пропустить DIV (F7 F3 = 2 байта)
  7) эпилог + IRET
  8) main: восстановить вектор 00h, напечатать дамп кадра, IP до/после,
     разбор флагов, результат через кадр, сравнение с Lab6_3

ЗАПУСК:
  Открыть в VS Code папку Lab6_5  ->  Ctrl+Shift+B
  (задача "Compile and Run (TASM -> DOSBox)")
  Альтернативы: "Compile and Debug in TD (DOSBox)" - отладчик;
              "Selftest: capture output" - сборка+запуск с перехватом
              вывода в build\run.txt (без ожидания клавиши, /dNOWAIT)

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
  дамп 12 слов кадра с пометкой "пролог компилятора" / "ПРОЦЕССОР";
  IP до add и после add (дельта 2 байта);
  quotient = 3525, remainder = 5 (выданы через слоты AX и DX);
  entries into PP = 1 (DIV НЕ исполнялась).

ПРОВЕРЕНО АВТОНОМНО (autotest.ps1, вывод в build\run.txt):
  старый вектор 00h = F000:1060 -> новый 0193:03E6 -> восстановлен F000:1060
  SP до особого случая FFFE -> FFF8 = 6 байт = 3 слова (снимается ДО ручного пролога)
  кадр SS:BP = 0193:FFE6, 12 слов: [bp+18] IP = 01C1 -> после add 01C3
  слоты, записанные ПП: [bp+16] AX = 0DC5, [bp+10] DX = 0005
  quotient = 3525, remainder = 5; входов в ПП = 1 (DIV НЕ исполнялась)
