Задание — Lab6_4 (шаг 4 из A6.txt, строки 51–53)

ФОРМУЛИРОВКА:
  "4. Проанализируйте заполнение стека. При выходе из обработчика
   прерываний пропустите команду, вызывающую особый случай
   (add [bp+18], 2)."

ЯЗЫК / СРЕДСТВО: C + встроенный ассемблер, TCC, модель small (-ms), EXE.

ИСХОДНИК:  Lab6.c

ПРОИЗВОДИТСЯ ДАМП КАДРА ОБРАБОТЧИКА (12 слов) С ПОДПИСЯМИ:
  [bp+0 ] BP    [bp+2 ] DI    [bp+4 ] SI    [bp+6 ] DS    [bp+8 ] ES
  [bp+10] DX    [bp+12] CX    [bp+14] BX    [bp+16] AX     <- пролог КОМПИЛЯТОРА (9 слов)
  [bp+18] IP    [bp+20] CS    [bp+22] FLAGS                 <- кладёт ПРОЦЕССОР
  Отсюда 18 = 9 слов x 2 байта — то есть IP лежит сразу за прологом.

ПРОПУСК КОМАНДЫ:
  asm add word ptr [bp+18], 2
  DIV BX кодируется двумя байтами (F7 F3), поэтому +2 переносит выполнение
  на следующую команду: особый случай БОЛЬШЕ НЕ ПОВТОРЯЕТСЯ
  (сравните с Lab6_3, где IP не менялся и DIV исполнилась повторно).

РЕЗУЛЬТАТ ВЫДАЁТ САМ ОБРАБОТЧИК:
  ПП считает 24680 / 7 = 3525 ост. 5 и кладёт его прямо в слоты кадра:
  poke(SS:BP+16) = AX (частное), poke(SS:BP+10) = DX (остаток).
  После IRET и pop ax / pop dx main читает результат, хотя DIV не
  исполнялась ни разу.

ЗАПУСК:
  Открыть в VS Code папку Lab6_4  ->  Ctrl+Shift+B
  (задача "Compile and Run (TCC -> DOSBox)")
  Альтернативы: "Compile and Debug in TD (DOSBox)" - отладчик;
              "Selftest: capture output" - сборка+запуск с перехватом
              вывода в build\run.txt (без ожидания клавиши, /dNOWAIT)

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
  SP до INT и SP внутри ПП (дельта = 24 байта = 12 слов: 6 байт ЦП
  (IP, CS, FLAGS) + 18 байт пролога компилятора);
  таблица 12 слов с указанием источника каждого слова;
  IP до add и после add (разница = 2);
  CS и FLAGS из кадра, разбор флагов CF PF AF ZF SF TF IF;
  результат 3525, остаток 5 — выдан через слоты кадра; входы в ПП = 1.

ПРОВЕРЕНО АВТОНОМНО (autotest.ps1, вывод в build\run.txt):
  SS=038E BP=FFDE SP внутри ПП=FFDE; SP до INT=FFF6 -> дельта 24 байта = 12 слов
  кадр: [bp+0..16] = пролог (BP DI SI DS ES DX CX BX AX), [bp+18]=IP 0430,
        [bp+20]=CS 01A3, [bp+22]=FLAGS 7286 - положил ПРОЦЕССОР
  IP до add 0430 -> после add 0432 (разница 2 = длина DIV BX)
  24680 / 7 = 3525, остаток 5 (выданы через слоты [bp+16] и [bp+10]); входов = 1
